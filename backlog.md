Correctness verified via matching checksums between baseline and cached implementations. Branch: efficiency/cache-rasterio-handles. Safe with DataLoader num_workers>0 since each worker gets its own Dataset copy/cache; handles closed in __del__.
- [DONE 2026-09-28, run 36407871218, draft PR created] create_masks.py cluster_labels(): was CRS-transforming EVERY feature geometry on EVERY grid-cell iteration (O(cells*features) redundant fiona.transform.transform_geom + linear scan). Correctness verified: identical cluster count, total feature count, and per-cluster size distribution vs. baseline (via git stash before/after comparison of the real function). Branch: efficiency/spatial-index-cluster-labels. This is the highest-impact single-file fix found so far (only triggered when --labels.cluster_size_in_meters is set).
